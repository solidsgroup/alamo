======================================
:fas:`keyboard;fa-fw` Builder (alpha)
======================================

This page links to standalone input file builders generated from the current Alamo build configuration.
Each builder is generated from the JSON schema emitted by the corresponding executable in
``--parse-args`` mode, with source comments added to the schema before the HTML is produced.

.. warning::
   This is a new and very experimental Alamo feature.
   Generate or refresh these files with ``make docs-input-builders``.
