Notes from this run

Build

Local binary wasn't actually HDF5-enabled

lowmach-2d-hdf5-clang++ linked libhdf5 but AMReX itself had never been configured with USE_HDF5=TRUE, so it wrote native AMReX plotfiles instead of the *cell.h5 files the rate extractor needs. Reconfigured with ./configure --hdf5 and rebuilt AMReX and alamo from a clean object cache.

Fix

numpy 2.x scalar repr broke every sim launch

optimize_fullfeedback.py passed repr(pre_exponential) straight to the shell, which under numpy 2 renders as np.float64(0.0027) instead of a plain float. Cast to native Python float before use.

Physics

273 K ambient IC needed a preheat zone to ignite

fullfeedback's temperature_bound = 500 K zeroes the reaction mobility below that threshold. A naive blend from 273 K (solid) to 700 K (product gas) put the interface itself at only 486.5 K — below the bound, so nothing ever ignited. The template now holds a ~100 µm hot zone (700 K) at and ahead of the interface, decaying to 273 K further into the solid, so the front ignites and then relaxes into its own steady conductive preheat profile.
